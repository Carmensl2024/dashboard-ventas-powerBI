# dashboard-ventas-powerBI
Dashboard de análisis de ventas desarrollado con SQL y Power BI para la visualización de KPIs e insights de negocio.
# 📊 Dashboard de Análisis de Ventas

## 🧠 Descripción

Proyecto de análisis de datos enfocado en la limpieza, transformación y visualización de información de ventas. Se utilizaron consultas SQL para depuración de datos y Power BI para la creación de un dashboard interactivo orientado a la toma de decisiones.

---

## 🔧 Herramientas utilizadas

* MySQL
* Power BI

---

## ⚙️ Proceso

### 🔹 Limpieza de datos

* Eliminación de duplicados
* Corrección de inconsistencias (ciudades, fechas)

### 🔹 Transformación

* Estandarización de formatos
* Validación de tipos de datos

### 🔹 Análisis

* Ventas por ciudad
* Ventas por producto
* Comportamiento en el tiempo

### 🔹 Visualización

* KPIs principales
* Gráficos interactivos
* Segmentadores dinámicos

---

## 📈 KPIs

* Total Ventas
* Ticket Promedio
* Cantidad Facturas
* Cantidad Vendida

---

## 🔍 Insights

* Bogotá lidera las ventas totales
* Los laptops generan mayor ingreso
* Existe diferencia entre volumen y rentabilidad por producto
* Se identifican variaciones en el comportamiento de ventas en el tiempo
